Časomíra 0.1.0 pro Windows 64-bit

Doporučená instalace: spusťte Casomira-Setup-0.1.0.exe jako správce.
Instalátor nainstaluje aplikaci a ovladač virtuálních portů com0com,
potom nakonfiguruje systémové porty COM19 a COM20.

Casomira-0.1.0-windows-x64.exe je přenositelná verze aplikace.
Neinstaluje ovladač com0com; pro automatické nastavení portů použijte instalátor.
